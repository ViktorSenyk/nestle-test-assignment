# Running Shoe Product Page (Nestle test assignment)

A simple running shoe product page built with HTML, CSS & vanilla JavaScript. Product data comes from MockAPI

##[Live demo](https://nestle-test-assigment.netlify.app/)

## Features

- Photo gallery with different images for each color
- Size selection and quantity limits based on stock
- Size guide and product information tabs
- Mobile layout and keyboard navigation
- Loading skeleton and error messages

## Run locally

Open `index.html` in a browser. Product data and images need an internet connection

## Code checks

Run these commands with Node.js 24 and npm

```sh
npx --yes eslint@10.8.0 index.js
npx --yes prettier@3.9.9 --check .
```
